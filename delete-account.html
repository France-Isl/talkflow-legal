Удаление данных — «Языки с нуля»

Разработчик: Islam Akhtakhanov (ggooglov9@gmail.com). Обновлено 22 октября 2026 г.

С версии 1.5.0 в приложении нет аккаунтов и нет сервера: все ваши данные (прогресс, избранное, настройки) хранятся только на вашем устройстве.

Как удалить свои данные

  1. Удалите приложение — вместе с ним удаляются все его данные на устройстве; или
  2. Android → Настройки → Приложения → «Языки с нуля» → Память → «Очистить данные».

Рекламный идентификатор, который использует Google AdMob, сбрасывается или удаляется в настройках Android (Google → Реклама).

Если у вас был аккаунт в версии до 1.5.0

Старые версии позволяли создать аккаунт (почта и пароль или вход через Google) и синхронизировать прогресс. Сервер этих аккаунтов отключается, а его данные удаляются. Чтобы удалить ваш старый аккаунт раньше, напишите на ggooglov9@gmail.com с той почты, на которую он был создан. Удаляется всё: адрес почты, синхронизированный прогресс, избранное. Срок — до 30 дней; ответ придёт на ту же почту.

Data deletion — “Languages from Zero”

Developer: Islam Akhtakhanov (ggooglov9@gmail.com). Updated October 22, 2026.

Since version 1.5.0 the app has no accounts and no server: all your data (progress, favourites, settings) is stored only on your device.

How to delete your data

  1. Uninstall the app — all its data on the device is deleted with it; or
  2. Android → Settings → Apps → “Languages from Zero” → Storage → “Clear data”.

The advertising ID used by Google AdMob can be reset or deleted in Android settings (Google → Ads).

If you had an account in a version before 1.5.0

Older versions allowed creating an account (e-mail and password or Google sign-in) to sync progress. The server for these accounts is being shut down and its data deleted. To delete your old account sooner, write to ggooglov9@gmail.com from the e-mail the account was created with. Everything is deleted: the e-mail address, synced progress, favourites. Within 30 days; the reply goes to the same e-mail.

Suppression des données — « Langues à partir de zéro »

Développeur : Islam Akhtakhanov (ggooglov9@gmail.com). Mis à jour le 22 octobre 2026.

Depuis la version 1.5.0, l'application n'a ni compte ni serveur : toutes vos données (progrès, favoris, réglages) sont stockées uniquement sur votre appareil.

Comment supprimer vos données

  1. Désinstallez l'application — toutes ses données sur l'appareil sont supprimées avec elle ; ou
  2. Android → Paramètres → Applications → « Langues à partir de zéro » → Stockage → « Effacer les données ».

L'identifiant publicitaire utilisé par Google AdMob se réinitialise ou se supprime dans les réglages Android (Google → Annonces).

Si vous aviez un compte dans une version antérieure à la 1.5.0

Les anciennes versions permettaient de créer un compte (e-mail et mot de passe ou connexion Google) pour synchroniser les progrès. Le serveur de ces comptes est arrêté et ses données supprimées. Pour supprimer votre ancien compte plus tôt, écrivez à ggooglov9@gmail.com depuis l'adresse e-mail utilisée à la création. Tout est supprimé : adresse e-mail, progrès synchronisés, favoris. Sous 30 jours ; la réponse arrive sur la même adresse.
