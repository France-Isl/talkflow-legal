# talkflow-legal

Публичные правовые документы приложения «Французский с нуля».

Страницы собираются из репозитория приложения командой
`dart run tools/bin/site_builder.dart` и выкладываются сюда — исходный
код приложения остаётся закрытым.

- [Политика конфиденциальности](https://france-isl.github.io/talkflow-legal/privacy.html)
